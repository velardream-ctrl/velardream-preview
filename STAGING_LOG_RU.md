## 2026-11-23 — RUN-214 · FLAC Hi-Res → MP3 (только тестовая ветка)

- Обновлён `mp3-converter/index.html`: FLAC (включая 24 бит / 96 и 192 кГц) сначала декодируется браузером, а при невозможности — локальной библиотекой `@wasm-audio-decoders/flac` версии 0.2.11 (WebAssembly).
- Декодер `mp3-converter/vendor/flac-decoder.min.js` скопирован из официального исходного репозитория, сохранён copyright; рядом `LICENSE-FLAC.txt` (MIT). Данные исходного FLAC на сервер не отправляются.
- Перед MP3-кодированием поток приводится к 44,1 кГц через OfflineAudioContext. Если старый Safari не поддерживает такое преобразование, включается медленный резервный фильтр с ограничением полосы (Lanczos).
- При выборе `.flac` по умолчанию устанавливается MP3 320 кбит/с (допустим ручной выбор 128/192); сохранены обычные аудиоформаты, приватность, выбор/перетаскивание файла, отмена, скачивание.
- Убрана старая дублирующая версия: `mp3-converter.html` перенаправляет на `mp3-converter/`. Тестовый основной сайт и данные Firebase не изменялись.
- **ПРОВЕРКА**: синтаксис новой страницы подтверждён; тесты с подставленными браузерными API и синтетическим PCM прошли для 96 кГц, 192 кГц, 96 кГц без OfflineAudioContext и WAV без FLAC-декодера. Это не тест реального FLAC-контейнера или реального MP3-кодировщика.
- **ОЖИДАЕТ**: успешная публикация GitHub Pages, тест на настоящем FLAC 16/44.1 и 24/96, 24/192, проверка качества готового MP3 и мобильный тест iPhone / старый iPad. Большие Hi-Res файлы могут не помещаться в память браузера; установлен лимит размера исходного файла 120 МБ и длительности 45 минут. Код только в test/mp3-converter-20261122; production не менялся.
