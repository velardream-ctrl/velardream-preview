## 2026-11-23 — RUN-222 · Сохранение стилей при подготовке экспорта Suno

- Экспорт из Suno нужен с **полными Lyrics** и отдельно подтверждённым `Style of Music` — если официальный MCP разрешает читать этот параметр. Не смешивать Lyrics (`metadata.prompt`) и стиль (`metadata.tags` / `style_of_music`), не сочинять стиль, если поле отсутствует.
- `suno-lyrics-import/prepare.js` теперь добавляет `sunoStyle`, `sunoCues` и `sunoVersions[]` в каждой проверочной записи. В `sunoVersions[]` сохраняются ID, название, URL, **отдельный стиль каждой музыкальной версии** из исходного `duplicates[]`. Одинаковый текст НЕ означает одинаковую аранжировку.
- Подготовитель на GitHub Pages остаётся **только локальным анализом JSON**. Без Suno токенов, скрытого API, записи в Firestore или массового изменения сайта. Интеграция с будущей приватной картотекой Studio будет отдельной безопасной операцией после подтверждения реального формата Suno.
- Тесты `tests/test-suno-lyrics-import.mjs` дополнены проверкой двух разных музыкальных стилей для одного текста.
