Конфиденциально. Исходное аудио обрабатывается только в вашем браузере и не попадает в базу Velar Dream.

FLAC Hi-Res. FLAC 16/24 бит, включая 96 и 192 кГц, преобразуется в MP3 с частотой 44,1 кГц. Качество MP3 — на выбор: 128/192/320 кбит/с.

Совместимость. Для FLAC, который не читает браузер, используется отдельный декодер WebAssembly. Нужен интернет для первой загрузки MP3-библиотеки; на старых iPad большие Hi-Res файлы могут не поместиться в память. DRM и ссылки Spotify/YouTube не поддерживаются.

Конвертируйте аудио, на которое у вас есть права. MP3 создаётся с помощью lamejs (LGPL-3.0); для FLAC при необходимости используется @wasm-audio-decoders/flac (MIT). FLAC-декодер загружается с сайта Velar Dream, MP3-кодировщик — из CDN. Аудиофайлы не отправляются на сервер.
