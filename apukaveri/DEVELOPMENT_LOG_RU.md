# Журнал разработки Apukaveri

## 27.11.2026 — этап 1, локальный серверный стенд

- Исходная публичная демоверсия подтверждена на https://apukaveri-preview.velardream.workers.dev/ после коммита `7a9a45c511ef898c288c5f83de5ecf437fefe7d9`. Каталог содержит 18 услуг. Профиль публичной демоверсии хранится в браузере.
- Зафиксировали восемь этапов и условия приёмки в LAUNCH_PLAN_RU.md. Подготовили отдельную сборку интерфейса для локального Worker с D1. Доступ к /admin зависит от сессии владельца, прямой путь к HTML отсутствует в публичном списке маршрутов. Локальная конфигурация блокирует внешний доступ. Секреты и облачные ресурсы не задействовались.
- Проверки: Node 3/3, семь миграций на чистой локальной D1, Wrangler dry-run и обе сборки. Node проверил доступ владельца, отсутствие доступа без сессии, чтение 18 категорий и сохранение данных. Первый запуск workerd остановился на `uv_interface_addresses`. С явными параметрами `--ip 127.0.0.1 --inspector-port 0` запуск и HTTP-проверка прошли. Главная, /sandbox.html и /api/categories ответили 200, каталог вернул 18 записей, /admin без входа вернул 401, а прямые пути к HTML вернули 404. Сквозной браузерный сценарий на Worker остаётся открытым. Код этапа сохранён в коммите `abde5110fe0597e64f238198065e5283ffe2d259`.
- Воспроизведение из каталога apukaveri: `node build-static.mjs --server`, `npx wrangler@4 d1 migrations apply apukaveri-local-test --local -c wrangler.local.jsonc`, `npx wrangler@4 dev --local -c wrangler.local.jsonc`. Открыть `/sandbox.html`. `node --test tests/*.mjs` запускает проверки без Wrangler. `node build-static.mjs` собирает публичную демоверсию в отдельный каталог.

## Точка продолжения

1. Пройти сквозной сценарий локального Worker в браузере, включая вход владельца и регистрацию тестировщика. Для HTTP-маршрутов и доступа владельца уже есть проверки.
2. Подготовить отдельную конфигурацию закрытого облачного стенда. Проверку доступа выполнить до отдачи HTML и до обработки API. Предусмотреть отдельную тестовую доставку кодов. Локальный консольный канал в облако не переносить.
3. Когда сборка закрытого стенда готова и требует входа в Cloudflare, передать владельцу окно авторизации. Подключить только отдельные ресурсы Apukaveri. Маршруты публичной демоверсии обслуживает прежняя конфигурация wrangler.jsonc.
