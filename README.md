## RUN-213: проверка MP3-конвертера из тестовой ветки

Исходная страница находится в `test/mp3-converter-20261122` → `mp3-converter/index.html`; код уже есть в GitHub, но без включённого GitHub Pages публичный URL даёт ошибку 404.

**Однократное включение GitHub Pages владельцем репозитория:**
1. Открыть `https://github.com/velardream-ctrl/velardream-preview/settings/pages`.
2. В `Build and deployment → Source` выбрать **Deploy from a branch**.
3. В `Branch` выбрать **test/mp3-converter-20261122**, каталог **/(root)** и нажать **Save**.
4. Проверить публикацию во вкладке Actions / Pages и затем открыть `https://velardream-ctrl.github.io/velardream-preview/mp3-converter/`.

Этот способ не использует workflow GitHub Actions, поскольку при публикации непосредственно из ветки GitHub Pages сам запускает стандартную сборку. Рабочий репозиторий `velar-music-manager`, домен `velardream.com`, Firebase и доступ к Studio не изменяются. Важно: открытие URL не равно проверке конвертации — отдельно проверить WAV/M4A → MP3 на iPhone Safari и старом iPad.

### Поддержка FLAC Hi-Res в тестовом конвертере
- Каноническая страница: `/mp3-converter/`, файл в ветке `test/mp3-converter-20261122`.
- Для FLAC браузер сначала пробует нативное декодирование, затем локально поставляемую библиотеку WASM; 96/192 кГц преобразуются в 44,1 кГц перед MP3.
- Для FLAC MP3 320 кбит/с выбирается автоматически, но можно изменить на 128/192.
- Реальные FLAC и старый iPad ещё **не прошли ручные проверки**. Страница публично откроется только после публикации ветки через Settings → Pages.

### RUN-215: универсальный аудиоконвертер (23.11.2026)

Тестовый URL: https://velardream-ctrl.github.io/velardream-preview/mp3-converter/

**Выходные форматы:**
- MP3 (с потерями): 128 / 192 / 320 кбит/с, выход 44,1 кГц.
- WAV (PCM, без сжатия): 16 / 24 бит, исходная или выбранная частота дискретизации 44,1 / 48 / 96 кГц.
- FLAC (без потерь при сохранении исходной разрядности/частоты): 16 / 24 бит, сжатие 0 / 5 / 8, исходная или 44,1 / 48 / 96 кГц.

**Входы:** WAV (PCM), FLAC (через встроенный декодер), MP3/M4A/AAC и прочие форматы, которые декодирует браузер. Преобразование потерянного качества обратно в WAV/FLAC не восстанавливает исходный звук.

**Реализация:** mp3-converter/index.html + audio-converter.js; vendor/libflac-encoder.js (libflac.js 5.6.0, MIT), vendor/flac-decoder.min.js (MIT), MP3 lamejs 1.2.1 (LGPL-3.0). Все аудиобайты обрабатываются локально, загружаются только библиотеки, никаких POST/загрузок в Firebase или Drive. Предохранители: вход не более 120 МБ, до 45 минут, несжатый WAV ограничен 256 МБ. При декодировании MP3/M4A/AAC браузер может изменить частоту и точность до перекодирования.

**Проверка:** синтаксис JS и smoke-tests, а также сценарии с синтетическим PCM для WAV→MP3, WAV→WAV и WAV→FLAC, прошли. Реальные FLAC/M4A, большие файлы, Safari и iPad требуют отдельной ручной проверки. Для smoke-tests из корня репозитория: `node tests/test-audio-converter.mjs`.

Этот код только в test/mp3-converter-20261122; основной velardream.com не менялся.

## RUN-217 — Мастерская артиста / локальный кабинет

Тестовая страница: [Мастерская артиста](https://velardream-ctrl.github.io/velardream-preview/singer-studio/).

Доступны подготовка минусовки к своему голосу, независимое изменение тональности (−6..+6 полутонов) и темпа (70–130%), сравнение с оригиналом, сохранение MP3 (192/320 кбит/с), WAV/FLAC (16/24 бит), локальное сценическое имя и сохранение до 12 наборов настроек песен. Данные аудио не отправляются на сервер. В тестовой версии **нет настоящей авторизации и синхронизации**; локальный кабинет хранит только настройки в браузере. AI-удаление вокала — будущая функция, сейчас недоступна.

Подробный журнал и план дальнейшей разработки: [singer-studio/README_RU.md](singer-studio/README_RU.md). Тест: `node tests/test-singer-studio.mjs`. Не переносить в рабочий Velardream.com без устройства-тестов, согласования и отдельного PR.

## RUN-220 — Подготовка пакетного импорта текстов Suno

Сценарий: официальный авторизованный Suno MCP или разрешённый экспорт → JSON с названиями/текстами → локальная сверка с каталогом Velar Dream → отчёт для проверки → отдельный защищённый импорт в `vmm_lyrics`. Первая часть уже подготовлена в `suno-lyrics-import/`. Функция пока **не обращается к Suno и не пишет в Firestore**: прямое получение существующих текстов через Suno MCP требуется подтвердить на реальном авторизованном аккаунте, и только после этого создавать коннектор.

Подробности: [suno-lyrics-import/README_RU.md](suno-lyrics-import/README_RU.md). Test: `node tests/test-suno-lyrics-import.mjs`. Production без изменений.
