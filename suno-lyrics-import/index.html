Тексты и стили Suno — массовая подготовка

Перенос большого количества песен без ручного копирования. На первом этапе этот инструмент сверяет файлы экспорта и создаёт список текстов для проверки администратором Velar Dream. Он не подключается к аккаунту Suno напрямую и ничего не записывает в Firestore.

1. Выберите файлы

JSON, полученный через официальный Suno MCP/API: названия, полные Lyrics и, если доступны, реальные Style of Music. Для нескольких музыкальных версий с одним текстом сохраняем отдельные стили каждой версии. Не загружайте cookies, пароли или токены доступа. Список объектов с полями title, artist, sourceRow, upc. Если каталог не указан, все песни получат статус «Нужна сверка» — автоматической привязки не будет. Нужны для обнаружения дублей. Без этого файла скрипт не может гарантировать отсутствие уже существующих версий.

Ожидание файлов.

2. Проверка результата

Если Lyrics одинаковые, но версии имеют разные Style of Music, сохраняйте оба промпта в поле sunoVersions. Это только предварительный пакет проверки. Ничего не изменяется в существующей базе сайта. Не импортируйте файл напрямую в Firestore: для реальной записи необходим защищённый админский загрузчик с повторной сверкой совпадений.

Что будет дальше

Когда подтвердим, какие методы Suno позволяют законно выгрузить весь список песен с текстами, подключим этот формат к инструменту. Затем сделаем импорт в закрытую Studio только с правами владельца, предпросмотром дублей и возможностью отката.

Все загруженные сюда файлы обрабатываются только браузером. Здесь нет запросов к серверам, а данные не сохраняются после закрытия страницы.
