# Мастерская артиста · RUN-218

## Адрес
- [Тестовая страница](https://velardream-ctrl.github.io/velardream-preview/singer-studio/)
- Исходники: `singer-studio/index.html`, `singer-studio/studio.js`, `singer-studio/vendor/soundtouch.js`
- Только тестовая ветка `test/mp3-converter-20261122` репозитория `velardream-ctrl/velardream-preview`. **Основной velardream.com не меняется.**

## Возможности сейчас
1. Выбор своего аудиофайла (WAV, FLAC, MP3 и другие форматы, читаемые браузером).
2. Изменение тональности от −6 до +6 полутонов **без изменения скорости**.
3. Изменение темпа 70–130% **без изменения тональности**. Параметры можно сочетать.
4. Кнопка «Применить», прослушивание оригинала и обработанной версии, отмена обработки.
5. Сохранение результата в MP3 192/320 кбит/с, WAV PCM 16/24 бит или FLAC 16/24 бит. Для дополнительной конвертации есть ссылка на универсальный аудиоконвертер.
6. Раздел «Личный кабинет артиста» в **локальном режиме**: сценическое имя по желанию, до 12 сохранённых проектов с названием и настройками тональности и темпа. При повторной работе нужно снова выбрать исходный файл.

## Важно
- **Пока нет онлайн-регистрации, аккаунтов, синхронизации и облачного хранения.** Кабинет — локальная демонстрация рабочего пространства. Сценическое имя и пресеты сохраняются лишь в localStorage браузера. Очистка данных браузера уничтожит эти настройки.
- Исходные аудиофайлы и обработанные записи не сохраняются ни на сервер, ни в localStorage. Файлы доступны для скачивания по выбору пользователя.
- Для сохранения MP3 впервые требуется загрузить `lamejs@1.2.1` из jsDelivr. SoundTouchJS и FLAC библиотеки лежат на тестовой площадке.
- Для более предсказуемой обработки исходное аудио преобразуется в 44 100 Гц. Результат в WAV и FLAC — 16 бит; это **не** исходный несжатый Hi-Res. Сильные изменения высоты/темпа могут дать артефакты.
- Мобильные устройства: максимум 45 МБ исходного файла и 8 минут; остальные — максимум 80 МБ и 12 минут. Дополнительно WAV результат ограничен 256 МБ. Реальные старый iPad, iPhone и длительные записи **ещё не проверены на физических устройствах**.
- Используйте аудио с необходимыми правами.
- Для создания двух дорожек выберите файл и нажмите «Разделить вокал и музыку». Формат и дорожку для скачивания можно выбрать независимо. Кнопка «Открыть минусовку в редакторе» передаёт PCM внутри страницы.

## Библиотеки и права
- Изменение темпа/тональности: [SoundTouchJS v0.3.0](https://github.com/cutterbl/SoundTouchJS) (LGPL-2.1); исходная библиотека в `vendor/soundtouch.js`, лицензия в `vendor/LICENSE-SOUNDTOUCH.txt`.
- MP3: [lamejs](https://github.com/zhuker/lamejs) (LGPL-3.0).
- FLAC decoder: [wasm-audio-decoders](https://github.com/eshaz/wasm-audio-decoders) (MIT).
- FLAC encoder: [libflac.js](https://github.com/mmig/libflac.js) (MIT).
- При дальнейшем коммерческом использовании проверять соблюдение условий лицензий (включая доступность исходников и уведомления).

## AI-сепарация в RUN-218

Velar Mask 1.0 — небольшая регрессионная нейросеть для спектральной маски. Собственные веса и движок под MIT, условия в LICENSE-VELAR-MASK.txt. Обучение с нуля по известным голосовым и инструментальным спектрам 96 процедурных смесей. Предобученные сторонние веса отсутствуют. Модель загружается с этой же страницы по относительному адресу velar-mask-v1.json (5394 байта, SHA-256 d0e82f829d55a28554b493bc71aef4c6b4a439c6ec6cb18f4c624dc5688860ac). Веса остаются в рабочем потоке между песнями. Отмена завершает поток, повторный запуск допускает использование HTTP-кэша.

MLP 11–20–12–1 оценивает долю энергии вокала для каждого спектрального отсчёта. STFT 2048/1024, 44,1 кГц. Обработка каждого канала сохраняет число каналов, однако пространственный образ может измениться. Минусовка равна разности между записью и оценённым вокалом. Модель может принять солирующий инструмент за голос. Выделение только основного голоса среди бэк-вокала не гарантируется.

Рассмотрены [HTDemucs в ONNX Runtime Web](https://stemsplit.github.io/demucs-onnx/browser/) (около 166 МБ только веса fp16), [MDX в браузере](https://github.com/incidentist/web-audio-separation) и [Spleeter](https://github.com/deezer/spleeter/issues/957). Для мобильной тестовой версии выбрана собственная компактная модель. Она работает на CPU в Web Worker без WebGPU, WASM, платного сервиса и дополнительных библиотек. Сравнительных измерений качества с Demucs и MDX пока нет. Библиотеки обучения NumPy, SciPy и scikit-learn не входят в клиентскую поставку.

### Проверки

Из корня проекта выполнить node tests/test-singer-studio.mjs и node tests/test-audio-converter.mjs. Для тестов качества нужны Python, NumPy, SciPy, scikit-learn и FFmpeg с flite. Команда python tests/run218/quality.py запускает опубликованный JS-движок на трёх отдельных контрольных смесях и проверяет восстановление их суммы. Для четвёртого теста передать путь к [Joy to the World, LibriVox, public domain](https://commons.wikimedia.org/wiki/File:Joy-to-the-World_KB.ogg). Используются секунды 8–11 и сгенерированное сопровождение. Запись хора используется только для проверки. Обучение воспроизводится командой OPENBLAS_NUM_THREADS=1 python tests/run218/train.py.

Улучшение отношения нужного компонента к примеси относительно входа, по коэффициентам линейной проекции на оба эталона, дБ (вокал / минусовка): синтетическое пение 10,3 / 17,5 и 16,9 / 14,6, синтез речи 7,2 / 2,4, запись хора 13,9 / 11,3. Метрика учитывает проникновение одного источника в другой, но не оценивает все искажения.

Для сквозного теста установить Playwright Python, задать CHROME_BIN путём к Chromium, выполнить python tests/run218/browser.py. Тест подаёт файлы репозитория через Playwright. LAME_JS может указывать на локальную копию lamejs 1.2.1 из jsDelivr. В headless Chromium проверены загрузка WAV, ошибка получения модели, отмена и повторный запуск, повторный выбор файла, обе дорожки WAV, движение позиции плеера, реальные MP3 192/320 и FLAC, передача минусовки в редактор, +2 полутона при 85% и скачивание FLAC. Физическое прослушивание и Safari, Windows Chrome/Edge, iPhone и старый iPad остаются отдельными проверками.
